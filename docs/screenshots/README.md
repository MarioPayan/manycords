# Screenshots

Capture the actual extension reader with fictional messages and no personal account information. Do not use the design prototype as a product screenshot.

- `reader-light.png`: English reader in light mode, 1280 × 800 pixels.
- `reader-dark.png`: English reader in dark mode, 1280 × 800 pixels, with the same collection and content.
- `collections.png`: collection editor showing channel selection, 1280 × 800 pixels.
- `reader-es.png`: Spanish reader, 1280 × 800 pixels.

The product page selects `reader-light.png` or `reader-dark.png` using the visitor’s colour preference. The other two captures are for store listings. Until captured, the page displays a screenshot placeholder. Upload the actual PNG files to this directory before publishing GitHub Pages.
